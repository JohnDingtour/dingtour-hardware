## Product images

A consistent, licensed product-photo set with fewer than three fasteners per frame could not be assembled from Unsplash, Pexels, Pixabay, or Wikimedia Commons without mixing inconsistent styles or using crowded group shots. Each category therefore uses an original catalog illustration, with at most two items per frame and a shared graphite studio plate. The published files are JPEG.

## Logo

The page uses the A1 wordmark only: an italic DINGTOUR wordmark with a nail-tip T, file `logos/a1/a1-oblique-pin-on-dark.svg`, in the hero and the footer. The same mark is also stored as `logos/a1/a1-oblique-pin-on-dark.png`, `logos/a1/a1-oblique-pin-primary.svg`, and `logos/a1/a1-oblique-pin-primary.png`. No other mark is included.

In the on-dark SVGs, only the solid `#151412` background rectangle was removed so the mark can sit on the page colour. Letter and symbol paths and colours were not redrawn or recoloured.
