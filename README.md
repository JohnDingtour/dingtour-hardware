# Haiyan Dingtour Hardware

English brochure for Haiyan Dingtour Hardware Co., Ltd, an import-export company in Haiyan, China. The company supplies a full range of industrial fasteners. The range it exports is not limited to its own factory's products.

This repository is the site served by GitHub Pages. The custom domain in `CNAME` is dingtour-hardware.com.

The page is arranged as blocks B01–B17. Confirmed product types use white-background studio renderings. Draft types still use line drawings and are marked as drafts. There is no enquiry form and no checkout.

Enquiries: [john.dingtour@gmail.com](mailto:john.dingtour@gmail.com).

Photograph, illustration, and font credits are in [CREDITS.md](CREDITS.md). Barlow Condensed and Libre Franklin are bundled as woff2, with a ttf fallback, under the SIL Open Font License (`fonts/OFL-BarlowCondensed.txt`, `fonts/OFL-LibreFranklin.txt`).
